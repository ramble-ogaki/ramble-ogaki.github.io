# RAMBLE ホームページ

GitHub Pagesで公開できる、RAMBLE用のスマートフォン対応ホームページです。

## ファイル構成

- `index.html` — ホームページ本体
- `style.css` — デザイン・スマホ対応
- `images/ramble-store.jpg` — RAMBLE店舗写真

## GitHub Pagesで公開する手順

1. GitHubで新しいRepositoryを作成
2. Repository名を `ユーザー名.github.io` にする
3. このフォルダ内のファイルをすべてアップロード
4. Repositoryの「Settings」→「Pages」を開く
5. 「Deploy from a branch」を選び、Branchを `main` にする
6. 数分待つと `https://ユーザー名.github.io/` で公開できます

## 注意

営業時間・住所・電話番号などは、提供された店舗情報をもとに掲載しています。
営業時間等が変更になった場合は `index.html` を編集してください。
